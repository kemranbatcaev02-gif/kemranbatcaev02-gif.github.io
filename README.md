## 🎨 Дизайн и визуальные решения

- 🌑 **Цветовая палитра:** Глубокий ночной фон (`#06080b`), приподнятые поверхности (`#0c1016`) и неоновый электрический акцент (`#3ca6ff`).
- ✨ **Живая текстура:** Анимированный микро-шум (film grain) поверх страницы, создающий ощущение аналоговой текстуры дисплея.
- 🔠 **Премиальная типографика:**
  - `Unbounded` — футуристичные динамичные заголовки.
  - `Manrope` — эргономичный, легко читаемый текст.
  - `JetBrains Mono` — акцентные технические спецификации и код.
- 🧭 **Умный интерфейс:**
  - Плавающий адаптивный навбар с `backdrop-filter: blur(14px)`.
  - Индикатор прогресса скролла страницы в реальном времени.
  - Горизонтальная витрина проектов с динамическими карточками.

## 💻 Локальный запуск и разработка

Сайт написан на чистом нативном стеке без тяжелых сборщиков (Webpack / Vite):

```bash
# 1. Склонируйте репозиторий
git clone https://github.com/kemranbatcaev02-gif/kemranbatcaev02-gif.github.io.git
cd kemranbatcaev02-gif.github.io

# 2. Запустите локальный HTTP-сервер (любым удобным способом)
# Например, через Python:
python -m http.server 8000

# Или через VS Code Live Server / просто открыв index.html в браузере
```

Откройте в браузере: `http://localhost:8000`.
